Installera Beatriz på iPhone

Öppna denna sida i Safari på din iPhone.

  1. Tryck på Dela-ikonen.
  2. Välj Lägg till på hemskärmen.
  3. Namnge appen Beatriz.
  4. Starta appen från hemskärmen.
